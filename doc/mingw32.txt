Building on Windows
===================

These steps use MSYS2 (https://www.msys2.org/) and have not been tested
since the move to SDL3 and CMake. Run them in the "MSYS2 UCRT64" shell.

Setup
=====

pacman -S --needed make \
    mingw-w64-ucrt-x86_64-gcc \
    mingw-w64-ucrt-x86_64-cmake \
    mingw-w64-ucrt-x86_64-pkgconf \
    mingw-w64-ucrt-x86_64-sdl3 \
    mingw-w64-ucrt-x86_64-libmikmod

Build
=====

cmake -S . -B build -G "MSYS Makefiles"
cmake --build build

Run build/triplane.exe from the build directory, so that it finds
fokker.dks there.

Dist
====

Copy triplane.exe, fokker.dks and the DLLs it needs (see
"ldd build/triplane.exe", at least SDL3.dll and libmikmod-3.dll) into
one directory and zip it.
